Caricare tutti i file e le cartelle nella root del repository, sovrascrivendo i file precedenti.
Nuovi file: manifest.webmanifest, service-worker.js, icons/.

iPhone: apri il sito in Safari > Condividi > Aggiungi alla schermata Home. Avvia dall’icona per nascondere la barra URL.
Android: menu browser > Installa app/Aggiungi a schermata Home.
Il pulsante ⛶ prova la Fullscreen API sui browser supportati, altrimenti mostra le istruzioni.
Non è possibile nascondere forzatamente la barra URL di Safari da una normale scheda web.
